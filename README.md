# 🚀 Developer Portfolio

A single-page developer portfolio built with **React** + **Vite** and deployed to **GitHub Pages**.

### Note:

This will be a work-in-progress online portfolio. I'm still working on it and will improve the UI/UX as I go along.

## ✨ Features

- Single-page layout with smooth-scroll navigation
- Sections: Hero, About, Skills, Companies, Experience, Contact
- Data-driven content (edit one file to update everything)
- Responsive, mobile-first design
- Framer Motion scroll animations

## 🛠️ Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Framer Motion](https://www.framer.com/motion/)
- GitHub Actions for CI/CD deployment

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+) and npm

### Install

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open `http://localhost:5173`

### Build for production

```bash
npm run build
npm run preview
```
